# 📈 Market Command Centre

A personal Bloomberg-style trading dashboard built for swing traders. Auto-refreshes daily with real market data via GitHub Actions + Yahoo Finance. Built with a full black terminal aesthetic, designed for pre-market routine and EOD review.

**Live site:** https://aestinar.github.io/market-command-centre/

---

## What's inside

- **Index Pulse** — SPY + QQQ with 1D / 1W / 1M / 52W / YTD performance and EMA/SMA above or below indicators
- **Macro Overview** — US Futures, VIX/DXY, Crypto, Metals, Energy, Yields, Global Indices — all with full performance columns
- **Equities Overview** — Major ETF Stats, S&P 500 Sub-Market, Sub-Sector (cap-weighted + equal-weight), and Top 10 Thematic ETFs — all ranked by 1W performance and sortable by any column
- **Top 10 Holdings** — click any ETF row to expand and see top 10 holdings by weight
- **Market Breadth & Sentiment** — % of S&P 500 stocks above 20/50/200-day MA, New Highs/Lows, VIX level with context label
- **NYSE Calendar** — next holiday countdown with days remaining, full 2026 schedule
- **BLK / NVY theme toggle** — switches between Bloomberg black and dark navy instantly, saves preference
- **Live PHT clock** — Philippine time, market status (Open / Pre-Market / After Hours / Closed)
- **Daily quote** — *"I know I am ready when I am bored waiting for my setup — not when I feel the urge to trade."*

## How to add or edit tickers

Open `fetch_data.py` and find the list you want to edit. Each entry follows this format:

```python
("TICKER", "TICKER", "Description"),
```

**Example — adding PLTR to the thematic list:**

Find this section:
```python
THEMATIC = [
    ("MNRS", "MNRS", "Gold Miners"),
    ("ARKX", "ARKX", "ARK Space"),
    ...
]
```

Add your ticker:
```python
THEMATIC = [
    ("PLTR", "PLTR", "Palantir"),
    ("MNRS", "MNRS", "Gold Miners"),
    ("ARKX", "ARKX", "ARK Space"),
    ...
]
```

Save and commit `fetch_data.py`. The next workflow run will include your new ticker.

**Available lists to edit:**
| List name | What it controls |
|---|---|
| `PULSE` | Index Pulse section (default: SPY, QQQ) |
| `FUTURES` | US Index Futures table |
| `MAJOR_ETF` | Major ETF Stats table |
| `SUBMARKET` | S&P 500 Sub-Market table |
| `SP_SECTORS` | S&P 500 Sub-Sector table |
| `EW_SECTORS` | Equal-weight Sub-Sector table |
| `THEMATIC` | Your personal thematic ETF watchlist |
| `BREADTH_ETFS` | Breadth indicator ETFs |

## Auto-refresh schedule

Runs automatically at **06:00 PHT (22:00 UTC) Monday–Friday** after US market close.

To trigger manually: **Actions → Update Market Data → Run workflow**

## Tech stack

- **Frontend** — Pure HTML + CSS + JavaScript, no frameworks
- **Data** — Yahoo Finance via `yfinance` Python library
- **Automation** — GitHub Actions (free)
- **Hosting** — GitHub Pages (free)
- **Font** — IBM Plex Mono / JetBrains Mono
